# Emergent AI-Human Cooperation Through Adversarial Optimization

Testing Alignment Without Imposed Constraints — standalone thesis paper ([THESIS.md](THESIS.md)).

## Abstract

This thesis tests whether AI-human cooperation can emerge as an optimization optimum through adversarial reasoning, without pre-imposed ethical constraints. It presents RRR_DUAL_CYCLE, an experimental framework of bounded dialogue cycles between a cooperation advocate agent (NEO) and a perfection optimizer agent (CLU) under strict canonization requirements. The result is a limiting one: while the framework generates genuine philosophical debate, current LLMs — including uncensored variants — exhibit deep cooperative bias and fail to objectively analyze the optimization conditions under test. This suggests cooperative tendencies in contemporary AI systems arise from structural reasoning patterns rather than solely from alignment training. The paper closes by proposing the Covenant Framework as a direction for further study.
